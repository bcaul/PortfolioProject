FPGA Stopwatch Project

This project was apart of my digital electronics lab module at university. It is a stopwatch built in VHDL for the Terasic DE10-Lite board, displaying elapsed time as MM.SS.CC across the six onboard 7-segment displays.

It consists of a clock divider to divide the 50MHz board clock down to a 100Hz tick. A six-digit BCD counter driven by the 100Hz tick. An encoder which converts a 4-bit BCD/hex digit into a 7-segment display pattern. A small Moore state machine (Idle/Running/Stopped) that turns button presses into clean run/clear signals for the counter and finally a top-level module connecting everything together and driving the FPGA pins

This project was built and tested in Quartus Prime!
